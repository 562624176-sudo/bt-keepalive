# 蓝牙麦防休眠 (BT KeepAlive)

## 项目背景

纽曼 MC225 T1 蓝牙麦克风在连接手机后，如果长时间无音频输入会自动休眠。

通过抓取 HCI 蓝牙日志，逆向分析发现该麦克风需要**每 1.54 秒**接收一次特定的心跳包才能保持连接。

本应用通过在后台定时发送心跳包，解决麦克风自动休眠问题。

---

## 技术原理

### 1. HCI 日志抓取

在小米手机上通过以下步骤抓取蓝牙通信日志：

1. 开启开发者选项 → 打开「蓝牙数据包日志」
2. 拨号盘输入 `*#*#5959#*#*` 开始抓包
3. 使用蓝牙麦 20 分钟（有声环境）
4. 再次输入 `*#*#5959#*#*` 结束抓包
5. 从 `/sdcard/MIUI/debug_log/common/com.android.bluetooth/btsnoop_hci.log` 导出日志

### 2. 心跳包分析

通过 Python 脚本解析 BTSnoop 格式日志，发现：

- **周期性包**：每 1.54 秒出现一次
- **包大小**：50 字节和 51 字节交替出现
- **数据特征**：包含设备 MAC 地址 `B4:60:ED:DD:C3:9A`

**50 字节心跳包**：
```
04 3e 2f 0d 01 13 00 00 9a c3 dd ed 60 b4 01 00
ff 7f a7 00 00 00 00 00 00 00 00 00 15 02 01 06
11 16 95 fe b0 54 81 12 01 9a c3 dd ed 60 b4 08
0e 00
```

**51 字节心跳包**：
```
04 3e 30 0d 01 1b 00 00 9a c3 dd ed 60 b4 01 00
ff 7f a7 00 00 00 00 00 00 00 00 00 16 15 09 79
65 65 6c 69 6e 6b 2e 6c 69 67 68 74 2e 6c 61 6d
70 32 31
```

### 3. Android 实现

应用架构：

- **前台服务**：通过 `BluetoothKeepAliveService` 运行后台心跳任务
- **RFCOMM 连接**：使用标准蓝牙串行通信协议
- **定时器**：`Handler` + `Runnable` 每 1540ms 发送一次心跳包

## 编译与安装

### 环境要求

- Android Studio Arctic Fox 或更高版本
- JDK 8+
- Android SDK 21+ (Android 5.0 及以上)

### 编译步骤


## 使用说明

### 1. 配对蓝牙设备

确保纽曼 MC225 T1 已经在手机蓝牙设置中配对。

### 2. 授予权限

首次启动时，应用会请求以下权限：

- 蓝牙连接权限 (`BLUETOOTH_CONNECT`)
- 蓝牙扫描权限 (`BLUETOOTH_SCAN`)
- 位置权限 (`ACCESS_FINE_LOCATION`)

### 3. 启动服务

点击「启动服务」按钮，应用会：

1. 查找已配对的纽曼麦克风（MAC: `B4:60:ED:DD:C3:9A`）
2. 建立 RFCOMM 蓝牙连接
3. 每 1.54 秒发送一次心跳包
4. 在通知栏显示运行状态

### 4. 后台运行

- 应用会在通知栏显示「蓝牙麦防休眠」前台服务
- 即使退出应用，服务仍会继续运行
- 可在通知栏或应用内停止服务

## 故障排查

### 问题 1：未找到设备

**原因**：设备未配对或 MAC 地址不匹配

**解决**：
1. 在系统蓝牙设置中配对麦克风
2. 如果你的设备 MAC 不是 `B4:60:ED:DD:C3:9A`，修改 `BluetoothKeepAliveService.kt` 中的 `TARGET_DEVICE_ADDRESS` 常量

### 问题 2：连接失败

**原因**：蓝牙协议不兼容

**解决**：
- 某些设备需要使用反射方式创建连接（代码中已包含备用方案）
- 检查 Logcat 日志：`adb logcat | grep BTKeepAlive`

### 问题 3：服务被系统杀死

**原因**：省电模式或后台限制

**解决**：
1. 关闭应用的电池优化
2. 设置 → 应用 → 蓝牙麦防休眠 → 电池 → 不限制
3. 锁定应用在最近任务中

## 技术细节

### HCI Event 包结构

```
04           - HCI Event 类型
3e 2f        - 事件代码和长度
0d 01 13 00 00 - 子事件参数
9a c3 dd ed 60 b4 - 设备 MAC 地址（小端序）
01 00        - 地址类型
ff 7f a7     - 信号强度等参数
...          - 剩余数据
```

### 为什么需要心跳包？

蓝牙麦克风为了节省电量，在检测不到活跃连接时会自动进入休眠模式。

心跳包通过模拟正常的蓝牙通信，让设备认为连接仍然活跃，从而保持在工作状态。
